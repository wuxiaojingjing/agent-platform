# Eval

存放本 Agent 独立维护的评测数据、预期结果和验收说明。

- `fastpath-seed.yaml`：单轮快路径现状锁与业务真值。
- `context-continuation-cases.yaml`：多轮上下文改写、跨子 Agent 事实传递、异构接入与冲突处理契约。
- `model-knowledge-admission-cases.yaml`：模型失败分类与知识补强准入的正负契约。

多轮用例中的 `known-gap` 表示目标行为已经冻结但当前实现尚未满足，不计入通过率。执行器必须分别报告
历史读取、上下文编译、上下文消费和最终结果；只证明读取到历史或最终回复碰巧正确，均不得判通过。

自然语言缺口先用基线模型复现，不先写 Java 关键词/正则分支。只有同一语义缺口在多个自然改写上稳定失败时，
才可以增补版本化 Prompt 示例、术语或能力知识。补强后必须同时跑通原失败用例、同义改写和无关上下文反例，并记录模型、Prompt 和资产版本。

`EVALUATED_GAP` 还必须证明：基线模型健康，失败发生在模型语义阶段，根因是领域知识缺口，并且至少两个自然改写稳定失败。
网络或模型不可用、Schema 非法、PolicyGate 拒绝、Runtime 未解析、单次偶发失败和通用模型能力不足都不得进入知识样例。
